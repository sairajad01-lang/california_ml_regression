u need to give in particular version model to the client as in this format

import numpy==2.3.5
import sklearn==1.7.2
import streamlit==1.51.0

import numpy>=2.3.5 ----->greater than 2.3.5 version
import numpy<=2.3.5 ------>older than 2.3.5 version
